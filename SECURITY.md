# Security Policy

## Supported Versions

The following versions of Catchim are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1.0 | No                 |

## Reporting a Vulnerability

We take the security of Catchim seriously. If you discover a security vulnerability in either the native C++ desktop application or the web editor, please report it responsibly:

1. **Do not create a public issue** on GitHub.
2. Email security concerns directly to the project maintainers or use GitHub's private vulnerability reporting feature under the Security tab.
3. Include detailed steps to reproduce the vulnerability, including platform information (Windows, Web, GPU configuration).

## Response Timeline

- **Initial Response:** Within 48 hours of report receipt.
- **Triage & Assessment:** Within 5 business days.
- **Fix & Disclosure:** Security patches will be prioritized and released as prompt minor updates.
